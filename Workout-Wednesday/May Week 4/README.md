\# MiniViz May Week 4 – Power BI Visualization Practice



\## Overview



This project is part of my Power BI visualization practice. The dashboard was recreated from the \*\*MiniViz May Week 4\*\* challenge with the theme:



> \*\*Every place has a vibe. What's dominant where?\*\*



The dataset is fictional and was created for learning and exploration. The main goal of this practice is to improve my dashboard layout, map visualization, slicer design, and visual storytelling skills.



\## Dashboard Preview



!\[Dashboard Screenshot](screenshot.png)



\## Objective



The objective of this dashboard is to show the dominant “vibe” by country and allow viewers to explore how different vibe categories are distributed across locations.



\## Key Visual Takeaways



\* The map makes it easy to see how vibe categories vary across different countries.

\* The slicer helps viewers focus on one specific vibe at a time instead of viewing all categories together.

\* The dashboard is designed around a single clear question, which keeps the layout simple and focused.

\* Because the data is location-based and categorical, a map visual is appropriate for showing geographic patterns.



\## Design Notes



In this dashboard, I focused on:



\* Using a map as the main visual because the question is geography-based

\* Placing the title at the top to clearly explain the purpose of the dashboard

\* Adding a slicer to support simple user interaction

\* Keeping the design minimal so the map remains the main focus

\* Using spacing and alignment to make the dashboard easier to read
